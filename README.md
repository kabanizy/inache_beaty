# Иначе

Статический лендинг на HTML, CSS и JavaScript. Откройте `index.html` в браузере или запустите локальный сервер командой `python -m http.server 4173 --bind 127.0.0.1`.

## Файлы

- `index.html` — структура, тексты, ссылки записи и телефона.
- `style.css` — оформление и адаптация под мобильные устройства.
- `script.js` — мобильное меню, скрытие навигации при прокрутке вниз на компьютере, галерея, просмотр фотографий и анимации.
- `assets/` — оптимизированные копии ваших снимков и локальные шрифты. Исходные фотографии и видео сохранены без изменений.

## Видео

В галерее подключён оптимизированный ролик преображения волос `assets/hair-film.mp4` и шесть фотографий. Ролик загружается при появлении в кадре, воспроизводится без звука и останавливается за пределами экрана. Нажатие на видео переключает воспроизведение; видимые кнопки поверх кадров убраны. Фотографии можно листать в ленте и в увеличенном просмотре. Лента занимает всю ширину экрана, её полоса прокрутки скрыта.

Декоративные анимации и мягкая прокрутка колёсиком учитывают `prefers-reduced-motion`; их также можно остановить кнопкой в подвале. На телефоне навигация всегда остаётся сверху, кнопка записи внутри hero скрыта. Блок «О нас» использует ваши файлы `scatch_onas.png` и `withlove_onas.png`, карточки увеличиваются при наведении на компьютере.
